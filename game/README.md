# Dragon Hunter

A Mega Man X–style 2D action-platformer built in Unity. You play a human
dragon-slayer who must defeat **four elemental dragons** — Fire, Ice, Water, and
Earth — each in their own stage, selected from a Mega Man X-style hub. Defeating a
dragon grants its element as a new weapon, and each dragon is weak to one element,
so the order you fight them in matters.

This is a **playable prototype with placeholder art**: every character and platform
is a tinted rectangle. All the mechanics are real; only the visuals are stand-ins,
and they're trivial to replace (swap the sprite on any object).

## Requirements

- **Unity 2022.3 LTS** (any 2022.3.x). Older 2021.3+ will likely work too.
- Install via [Unity Hub](https://unity.com/download).

## First-time setup (one menu click)

The scenes are **generated by an editor script** so the project opens cleanly
without hand-authored scene files.

1. Open **Unity Hub → Add → Add project from disk**, and select this `game/`
   folder. Open it (let Unity import; first import takes a minute).
2. In the top menu, run **`Dragon Hunter ▸ Build All Scenes`**.
   - This creates the Title, StageSelect, four dragon stages, Victory, and Game
     Over scenes under `Assets/Scenes/`, generates the placeholder sprite and the
     projectile prefab, ensures the `Ground` physics layer exists, and registers
     everything in **Build Settings**.
3. The **Title** scene opens automatically. Press **Play** (▶) at the top.

Re-running the menu command regenerates the scenes (safe to do anytime).

## Controls

| Action | Keys |
| --- | --- |
| Move | `A` / `D` or `←` / `→` |
| Jump (variable height) | `Space` / `W` / `↑` |
| Dash | `Left Shift` |
| Wall-slide / wall-jump | hold toward a wall while airborne, then `Jump` |
| Shoot (tap) / charge (hold then release) | `J` or `Ctrl` |
| Switch weapon | `Q` / `E`, or number keys `1`–`5` |
| Menus / stage select confirm | `Space` / `J` / `Enter` |

## The dragons and the weakness cycle

Each dragon takes **3× damage** from the element it is weak to, and your weapon
of that element also reads clearly against it.

| Dragon | Weak to | Attacks |
| --- | --- | --- |
| 🔥 Fire | **Earth** | 3-way fireball spread, charge dash |
| ❄️ Ice | **Fire** | falling icicle rain, low freeze breath |
| 💧 Water | **Ice** | arcing bubble lobs, hop-and-spray fan |
| ⛰️ Earth | **Water** | arcing boulders, ground-pound shockwaves |

You start with only the **Neutral** bolt (which always works, just slower).
A good clearing order that chains each unlocked weapon into the next dragon's
weakness is: **Earth → Fire → Ice → Water**.

## Swapping in real art

Every visible object uses a single white sprite tinted by code. To use real
sprites: assign your sprite to the `SpriteRenderer` on the player, a dragon, or
the projectile prefab. To stop the code re-tinting it, remove the `.color`
assignments in `PlayerWeapon`/`DragonBoss`/`StageSelectController`, or set the
sprite's vertex color usage as you prefer. Animations can be added with an
`Animator` on the same objects without touching the gameplay scripts.

## Tuning

Most feel parameters are public fields on the components, editable in the
Inspector: movement/jump/dash/wall values on `PlayerController`, health on
`PlayerHealth`, fire rate and charge on `PlayerWeapon`, and per-dragon stats on
each `*Dragon` component (health, attack speeds, projectile speeds).
